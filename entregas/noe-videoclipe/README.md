# A Arca de Noé — Videoclipe

Canção fornecida pelo usuário na íntegra, aproximadamente 4min02s, sem narração adicional. Livro pop-up em 26 trechos, com variações de câmera, movimentos suaves, marca e convite à inscrição no encerramento. Horizontal 1280 × 720, 24 fps, H.264/AAC estéreo.
