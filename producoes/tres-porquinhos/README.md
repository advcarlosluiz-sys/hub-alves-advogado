# Os Três Porquinhos — Contos de Gaitolé

Adaptação original em dez cenas, livro pop-up 3D, 3 minutos e 1 segundo.
Voz Thalita pt-BR, música Gaitolé, Gaitolé Completa (1) com redução durante as falas,
encerramento com a marca, YouTube @gaitolé, TikTok @gaitole0 e convite para inscrição.

O ZIP de mídia contém somente MP4, MP3s e instruções: extraia e abra ASSISTA-AQUI.mp4.
Nenhum atalho .cmd é necessário para assistir.

Fonte da apresentação: stories/joao.json é o arquivo de entrada legado do motor;
seu conteúdo nesta pasta é Os Três Porquinhos. Não é a história João e o Pé de Feijão.
O motor e scripts estão em engine/ e scripts/. Ilustrações novas em assets/porquinhos/.
MP3s reais da Thalita e manifesto em assets/narracao/; música em assets/musica/.

Para abrir o projeto de desenvolvimento, execute node scripts/serve.mjs (Node 22+).
O motor pode ser servido offline por HTTP local. O arquivo HTML usa módulos e não
abre por file://. A exportação no navegador inclui narração e música.
Os scripts de desenvolvimento não fazem parte do ZIP só para assistir.

As ilustrações foram criadas para esta adaptação. O conto tradicional foi adaptado
com final acolhedor: o lobo foge, os irmãos ficam seguros e aprendem a construir juntos.
